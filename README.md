# Railway Ticket Reservation System

## Project Overview
The Railway Ticket Reservation System is a Python-based application developed using Object-Oriented Programming (OOP). It allows users to create accounts, log in, view available trains, book railway tickets, view their bookings, and search for tickets using PNR numbers.

## Features
- User Registration and Login
- View Available Trains
- Display Train Details and Available Seats
- Book Tickets for Multiple Passengers
- Automatic PNR Number Generation
- Calculate Total Ticket Fare
- View Personal Booking History
- Search Tickets Using PNR Number
- Automatic Seat Availability Updates
- Input Validation and Error Handling
- User Logout

## Technologies Used
- Python

## Python Concepts Used
- Classes and Objects
- Constructors (`__init__`)
- Object-Oriented Programming
- Encapsulation
- Lists and Dictionaries
- Functions and Methods
- Loops and Conditional Statements
- Exception Handling
- Random Module

## Main Classes
- **User:** Stores user account details.
- **Train:** Manages train information and available seats.
- **Passenger:** Stores passenger details.
- **Ticket:** Generates and displays ticket information.
- **RailwaySystem:** Handles registration, login, train searching, ticket booking, and other operations.

## How to Run
1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python railway_ticket_booking_system.py
```
